Title of dataset: Python script for training machine leanrning models for glass density prediction


Name/institution/contact information for:
    Principal Investigator (or person responsible for collecting the data): Paweł Stoch
    Data manager or custodian: Paweł Stoch

All scripts were written in Python 3.12.3 with external libraries: Scikit-learn 1.7.0, matplotlib 3.10.0, SHAP 0.48.0,  GlassPy, Matminer, 
The scripts are saved in JupyterNotebook file format (*.ipynb) and the zip compressed associated full dataset after screening in csv file format
 
File name structure:
Main folder: 1-DataCleaning.ipynb - set of scripts to download and data clean
Main folder: 2-Featuring.ipynb - set of scripts to featurizing the cleand data
Main folder: 3-ML_Models.ipynd - set of script to train and tune the machine leanrning models
Main folder: 4-Analysis.ipynb - set of scripts to analyze the results of the training
Main folder: data_cleand.zip - zip compressed full dataset for model training in csv format

File formats: IPYNB, ZIP
